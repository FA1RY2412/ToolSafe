# Перевірка ToolSafe

Фактична дата підготовки і перевірки 03.10.2026. Узгоджені дати Git не є днями виконання.

## Підтверджено

- Репозиторій перед перенесенням містив лише `.git`, main був unborn. Перенесено весь каталог у Work. SHA256 `.git/config` до і після: `9e2300d1b53320231e0a173aff190e6e742fdfc9ffbb22585295816f2797932d`. Identity та origin збережено.
- Порівняно 100 файлів шаблону побайтно. Firmware, `.ioc`, diagram, Dockerfile, Makefile, ліцензії без змін. Оригінальний README зберігається як `boilerplate-README.md`.
- Код підтверджує USART2 PA2/PA3 AF1, 115200 8N1, передачу через `__io_putchar`/`HAL_UART_Transmit`, LED PA5 та `HAL_Delay(1000)`. I²C1 PB8/PB9 налаштовано, обмін із сенсором не виконували.
- Дві чисті firmware-збірки `make clean` + `make build IMAGE=toolsafe-stm32-build:local` завершились кодом 0. Docker-образ зібрано з Dockerfile, на другій збірці використано кеш образа. Це дві компіляції після очищення firmware/build, а не дві збірки образа без кешу.
- Реальний хост macOS 27.0.1 arm64; Docker 29.6.1, context desktop-linux, образ linux/arm64. GCC 10.3.1. Метадані: [environment.txt](evidence/environment.txt) та [toolchain.txt](evidence/toolchain.txt).
- ELF/HEX/BIN двох чистих збірок мають однакові SHA256. Розмір за `arm-none-eabi-size`: text 13464, data 120, bss 1808 байтів. Це результат збірки, не вимір часу чи пам'яті під навантаженням сенсорів.
- У VS Code на Mac команда `Wokwi: Start Simulator` запустила ToolSafe з чинною встановленою ліцензією. Trial і нові ключі не активували. Видно ready, послідовні tick, перезапуск з tick 0 та два стани LED.

## Реальні знімки Wokwi

[Початок після перезапуску](evidence/wokwi-start.png): назва ToolSafe, `STM32C031C6 ready`, tick 0…10, час симулятора 00:10.070. Старі tick вище належать попередньому запуску цієї самої копії.

[LED вимкнений](evidence/wokwi-led-off.png): час 00:30.662, tick 30. [LED увімкнений](evidence/wokwi-led-on.png): симуляцію поставлено на паузу в 00:55.637, tick 55, GPIO показує OUT High. Знімки фіксують фактичні стани. Точну тривалість імпульсу аналізатором не вимірювали; секундний інтервал підтверджено кодом та спостереженням. [SHA знімків](evidence/screenshots.sha256).

Підпис у шапці Wokwi належить встановленій ліцензії. Він не встановлює ПІБ чи групу власника ToolSafe.

## Не виконано

У цьому чаті Ubuntu 24.04 VM не запускали і не перевіряли. Read-only SSH через наявний alias `ubuntu-vm` завершився `Network is unreachable`, код 255; [фіксація](evidence/vm-access.txt). Передача файлів і збірка у VM не відбулися. VirtualBox є на Mac, але `VBoxManage list vms` і `list runningvms` не показали зареєстрованих VM у цьому користувацькому профілі. Це не перевірка стану іншого комп'ютера.

Сенсори не додано, FR-03–FR-12 не реалізовано і не протестовано. T01/T02 підтверджені запуском; точна осцилограма PA5 ще відсутня. CubeMX не відкривали, його Pinout/Clock screenshots ще потрібні. Фізичні PIR/LDR і повне читання PDF виробника MPU потребують завершення.
